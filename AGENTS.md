# Contexto y reglas del proyecto

## Proyecto

Este repositorio contiene una página estática en español para promocionar y vender un
curso de Excel. La página actual presenta el curso, los resultados de aprendizaje, un
temario por módulos y un llamado a solicitar información.

## Estructura y tecnología

- `index.html`: contenido y estructura semántica de la landing page.
- `Style.css`: estilos, diseño adaptable y preferencias de movimiento reducido.
- El proyecto no tiene actualmente backend, framework, gestor de paquetes ni suite de
  pruebas configurada. Comprueba los archivos disponibles antes de proponer comandos.
- Conserva el nombre y las mayúsculas de `Style.css` en los enlaces.

## Reglas de producto y contenido

- Mantén el idioma español, el tono claro y el diseño existente, salvo que el usuario
  apruebe un cambio de marca o de dirección visual.
- No inventes ni publiques precio, descuentos, fechas, duración, modalidad,
  certificaciones, testimonios, credenciales del instructor, datos personales o medios
  de pago. Solicita la información que falte antes de incorporarla.
- El botón de correo de contacto usa la dirección que proporcionó el usuario; no
  sustituyas el correo por un marcador de posición ni muestres instrucciones internas
  en la página pública.
- No afirmes que un pago, formulario o inscripción funciona si no existe una integración
  real y verificada.

## Calidad y validación

- Prioriza HTML semántico, navegación por teclado, etiquetas accesibles, enlaces
  funcionales, diseño adaptable sin desbordamiento y respeto a `prefers-reduced-motion`.
- Evita dependencias, servicios externos y herramientas nuevas si el HTML y CSS actuales
  resuelven el requisito.
- Valida cada cambio con las herramientas disponibles. Para cambios visuales, revisa
  escritorio y móvil en navegador cuando sea posible; informa cualquier comprobación
  que no se haya podido ejecutar.
- Limita cada cambio al requisito aprobado y no elimines ni reviertas trabajo ajeno.
